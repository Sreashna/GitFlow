# CozyCorners - AR Furniture E-Commerce App

**CozyCorners** is an innovative **Android-based furniture e-commerce application** that leverages Augmented Reality (AR) to allow users to visualize furniture in their real-world spaces. It provides an easy-to-use interface to browse furniture, place orders, and manage shipping details, all while enjoying the benefits of cutting-edge AR technology.

## Key Features
- **AR Visualization**: Use **ARSceneView** to see how furniture fits in your room in real-time, providing a true-to-life experience of the product before purchasing.
- **Product Browsing**: Browse through a wide variety of furniture categories with images, descriptions, and prices.
- **API Integration**: Dynamic product data fetching via **Retrofit** from a remote API.
- **User Authentication**: User registration and login functionality through **Firebase Authentication** for secure access.
- **Address Management**: Users can add, modify, and manage multiple shipping addresses, stored locally using **RoomDB**.
- **Custom Chatbot**: An AI-powered chatbot integrated into the home screen to assist users with their inquiries and guide them through the app.
- **Product Reviews**: Ability to write and upload product reviews, including images.

## Tech Stack
- **Programming Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **AR**: **ARSceneView** for augmented reality visualization of products in the user's environment.
- **Networking**: **Retrofit** for API calls to fetch product details.
- **Backend**: **Firebase** for authentication and database storage.
- **Local Storage**: **RoomDB** for storing user addresses and product reviews locally.
- **Image Loading**: **Glide** for efficient image loading and display.
- **Architecture**: MVVM (Model-View-ViewModel) architecture to ensure scalability and maintainability.
